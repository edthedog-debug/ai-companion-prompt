# AI Companion Prompt

A lightweight Node.js application to interact with Google Gemini using custom system instructions for creative, grounded, and bilingual (English/Spanish) conversations.

## Features
- **Bilingual Support**: Automatically detects and responds in English or Spanish based on user input.
- **Custom Persona**: Configured via system instructions to maintain a sharp, philosophical, and pragmatic conversational style.
- **Interactive CLI**: Real-time multi-turn chat directly from your terminal.

## Prerequisites
- Node.js (v18 or higher)
- A Google Gemini API Key
